# 力量体系（锁死版）

## 大境界（九州通行）

炼气 → 筑基 → 金丹 → 元婴 → 化神 → 合体 → 大乘 → 渡劫 → 散仙

每境四阶：**初 / 中 / 后 / 巅峰**

跨大境 = 质变（寿元、神识、法力总量、可驱使的天地之力跃迁）。

## 各境读者可读锚点

| 境界 | 读者感受 | 典型能力 |
|------|----------|----------|
| 炼气 | 入门打架 | 外放灵气、初级术法 |
| 筑基 | 正式修士 | 御器短飞、持久战 |
| 金丹 | 一城高手 | 法力凝实、可开宗立派底层 |
| 元婴 | 一国震慑 | 元婴出窍、难彻底斩杀 |
| 化神 | 规则初触 | 局部场域、神识碾压 |
| 合体及以上 | 卷级BOSS | 搬山填海、染指道则 |

## 资源阶梯（从低到高）

灵石 < 丹药 < 功法残篇 < 完整功法感悟 < 血脉碎片 < 灵宝本源 < 敌人修为本源 < 道则碎片

**写作约束：** 低阶资源只能「稳」，不能「破境」；破大境必须吃到对应阶梯的资源 + 剧情兑现。

## 战力对照（防战力崩）

- 同境：技巧/信息差/异纹克制可胜
- 高一小阶：可险胜（需代价）
- 高一大境：不可正面硬刚，必须阴谋/环境/反制道具
- 清道者：同境对「异纹持有者」视作高半境（克制属性）

## 禁止事项

1. 禁止无铺垫连跳两大境
2. 禁止「顿悟」单独破大境（最多破一小阶）
3. 禁止让炮灰突然具备跨两境战力
4. 禁止金手指无代价破上限
