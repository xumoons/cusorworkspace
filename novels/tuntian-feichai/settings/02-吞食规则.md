# 吞食规则与代价（锁死版）

这是本作金手指的唯一说明书。后文冲突、悬念、长期压迫都从这里长出来。

## 一、觉醒表现

- 载体：胸口黑色**异纹**（随吞食加深、蔓延）
- 感知：可「看见」附近可吞之物发亮；过强之物发烫/刺痛
- 本能语：万法可吞（非系统面板，无任务，无商城）

## 二、可吞清单

| 类型 | 效果 | 风险 |
|------|------|------|
| 灵草废料 / 低阶灵液 | 微调亲和、稳修为 | 杂质，需异纹过滤 |
| 功法残韵 / 残篇 | 获得对应战斗本能或术法片段 | 风格冲突时短期走火 |
| 完整功法感悟（击溃神魂后） | 大幅理解，可复现招式逻辑 | 异纹加深明显 |
| 血脉碎片 | 体质向某方向偏移 | 可能改变气机特征，易暴露 |
| 灵宝本源 | 兵器/法宝契合或拆解强化自身 | 宝器反噬 |
| 敌人修为本源 | 直接堆修为 | 最高风险，见「上限」 |
| 阵法节点能量 | 一次性爆发或破境催化剂 | 易被大势力感知 |

## 三、不可吞 / 强吞必死

1. **活着的完整意志**（未击溃神魂前不能吞人）
2. **因果锁死之物**（天道契约、清道印、部分祭阵核心）
3. **高两境以上完整本源**（强吞爆体）
4. **清道者的「修剪之力」本身**（反被标记）

## 四、硬性上限公式（写作时照此执行）

- 平常状态：最多稳定吞食 **同境或低一境** 资源
- 击溃神魂后：可吞 **高一小阶** 的功法感悟/部分修为
- 特殊场域（如乱星荒域、反祭阵）：上限临时 **+1 大境内一小阶**
- 任何一次「破大境」吞食：必须配合剧情高潮，不可日常刷

## 五、代价体系（越往后越重要）

### 1. 异纹积累
每吞必留痕。异纹浓度分四级（读者可感知）：

| 级 | 表现 | 后果 |
|----|------|------|
| I 淡纹 | 袖口可遮 | 几乎无事 |
| II 显纹 | 衣物难全遮 | 敏感修士可察觉气机邪异 |
| III 蔓纹 | 蔓延至颈/腕 | 清道者远程可感应方位 |
| IV 焚纹 | 灼热、梦魇 | 清道者必至；道心受噬 |

卷一结束前主角控制在 **II～III**，不可到 IV。

### 2. 风格污染
吞多了互斥功法，短期招式别扭，需「炼化章节」消化（正好可写成长缓冲，而非无意义日常）。

### 3. 清道者仇恨
异纹是「天道修剪名单」的定位符。浓度越高，刷新越近。  
**长期主线压迫源 = 清道者，不是某个宗门长老。**

### 4. 道心侵蚀（中后期解锁）
吞得越多，越容易把万物视为「食物」。若失控，会失去「选择不吞」的能力——这是最终内敌。

## 六、战斗中的吞食节奏（章法）

标准一战四拍：

1. **识别**：看见可吞亮点 / 烫点
2. **创造条件**：击溃、诱入阵、借环境
3. **吞**：一句话写清吞了什么、得了什么
4. **代价闪回**：异纹、污染、被监视感（可轻可重，但不能连续多章零代价）

## 七、爽点与平衡的写法口诀

- 爽：吞完立刻有可演示的新能力或修为涨幅
- 平：涨幅必须匹配资源阶梯
- 压：每 3～5 次有效吞食，安排一次「差点暴露 / 清道者感应」

## 八、禁止事项

1. 禁止把吞食写成经验条无脑升级
2. 禁止吞完毫无异纹反应
3. 禁止靠吞食解决一切社交/情感问题
4. 禁止提前展示「吞天道完整传承」（卷一最多残页级）
