# 第4–10章细纲（可直接开写）

写作要求：每章 4000–6000 字；章末钩子必留；吞食必须写清「吞了什么 / 得到什么 / 异纹变化」。

---

## 第4章｜废料也能吃

**本章任务：** 把金手指从「开挂」落成「生存策略」，让读者相信他能慢慢变强。

**开场：**  
测灵风波后，外门流言四起。王墨执事上门警告：三日一次测灵，异常再扩就送执法堂。

**过程：**
1. 陈渊不去争灵田，去药渣场、废丹坑、废弃洞府外围「捡亮点」。
2. 演示规则：废灵草可吞但涨幅小；一枚破损下阶储物袋残韵可吞，获得「空间感知」雏形（极弱）。
3. 赵虎派人暗中盯梢，被陈渊反将一军——不杀人，只废其一条手臂经脉（留活口传恐惧）。
4. 医药堂老柳出场：愿高价收「来路不明的战利品情报」，给陈渊一条路——外门大比冠军奖池丰厚。

**吞食记录：**
- 废灵草×若干 → 草木亲和微涨
- 储物残韵 → 微弱空间感知
- 异纹：I 级偏深，仍可遮

**兑现：** 炼气三 → 炼气四（稳涨，不炸场）

**章末钩子：** 大比名册公布，赵虎的名字和陈渊写在同一组。

---

## 第5章｜报名

**本章任务：** 立靶、加压、制造全场期待打脸。

**开场：** 报名处排长龙，有人公开起哄「祭品也配上台」。

**过程：**
1. 陈渊平静报名，测灵石显示炼气四，嘲讽升级为「偷学邪功」。
2. 周长老「路过」旁观，笑着说可参赛——实则想借大比公开观察异纹反应。
3. 苏晚首次远景出现：内门看台预留位，她在看「祭品名册」而非大比。
4. 陈渊夜审自身：异纹在测灵时会微热——大比是险地也是猎场。
5. 他制定策略：初赛只吞「战斗本能碎片」，不暴露吞修为；决赛才赌。

**吞食记录：** 无（蓄力章，允许一次「拒绝吞」的克制，强化角色智力）

**兑现：** 读者拿到「作战计划」，期待感拉满

**章末钩子：** 赵狂（赵虎师兄，筑基初）传来一句话：决赛见，挖了你的心祭刀。

## 第6章｜初赛

**本章任务：** 连续小爽点，展示战斗风格=选择猎物。

**赛制：** 擂台淘汰，可用兵器，禁杀（名义上）。

**过程：**
1. 第一场：对手是蛮力型炼气五。陈渊不硬刚，消耗后击溃其招式节奏，吞「力量传导本能」。
2. 第二场：对手灵巧剑修。陈渊用新吞的传导感预判发力点，反夺剑势，吞「步法残韵」。
3. 场外：周长老的亲传在记录「他为什么总能越打越顺」。
4. 陈渊故意在第三场打得更「普通」，降低威胁评价。
5. 赵虎在观众席脸色铁青，被同门嘲笑「连废柴都不如」。

**吞食记录：**
- 力量传导本能
- 步法残韵
- 异纹：仍 I 级，但战斗中闪过一次热意（清道者远感预告，极轻）

**兑现：** 连胜晋级；炼气四 → 炼气六（偏技巧堆叠+少量修为）

**章末钩子：** 苏晚派人送来一张无字符纸——点燃后只剩一句：别赢太快。

## 第7章｜天骄的目光

**本章任务：** 苏晚正式交接，埋「祭品互换」因果；关系定调为利益同盟而非恋爱。

**开场：** 陈渊夜至约定废园，苏晚独自等候。

**过程：**
1. 苏晚开条件：她要确认陈渊是不是「异常样本」；陈渊要活路与情报。
2. 情报交换：每年祭天名单由周长老拟定，宗主默许；个别「废脉」其实是被人为废掉。
3. 苏晚展示手腕内侧契约纹（与异纹不同）：天骄契约会抽走她部分悟性与机缘。
4. 陈渊试探：你为何不逃？答：逃则宗门拿她族人祭阵。
5. 交易达成：陈渊大比不要在周长老面前暴露「吞修为」；苏晚给半张藏经阁值夜表。
6. 离别时苏晚补刀：你本不该出现在今年名单——有人把你和另一个名字换过。

**吞食记录：** 无（信息章）

**兑现：** 世界观揭一层；主角从「报仇」升级为「查换名真相」

**章末钩子：** 值夜表角落有一行被擦掉的字迹，隐约像「清道」。

## 第8章｜决赛

**本章任务：** 卷一第一个「险胜高潮」；完成筑基门槛资源获取。

**对手：** 赵狂，筑基初，持宗门发放的青锋剑，擅「裂风」进阶式。

**过程：**
1. 开战即压制。陈渊炼气六硬扛筑基，观众等着看死。
2. 陈渊不硬碰剑气，用步法残韵+力量传导打「人」不打「招」。
3. 中段：被一剑削开肩口，血溅；异纹几乎暴露，他用焦土泥污遮住。
4. 关键转折：故意卖破绽诱赵狂催动完整裂风进阶——神魂因催功微散。
5. 陈渊抓住半息窗口，肘击神庭，击溃其战斗意志（未致死，符合赛规擦边）。
6. 吞「筑基感悟」+裂风完整逻辑；当场不开大，装成险胜昏迷边缘。

**吞食记录：**
- 筑基感悟（核心）
- 裂风完整逻辑
- 异纹：冲到 II 级边缘，必须立即收手

**兑现：** 夺魁；全场死寂后爆发；周长老脸色铁青却当众祝贺

**章末钩子：** 奖励不是当场发——「三日后于祭坛侧殿领赏」。陈渊闻见侧殿方向有祭阵残味。

## 第9章｜有毒的奖赏

**本章任务：** 把「胜利」变成「杀局」；丹药陷阱推动破境方式。

**开场：** 侧殿领赏，周长老亲至，笑容满面。

**过程：**
1. 奖品：筑基丹一枚、灵石百、外门小院。表面大方。
2. 陈渊感知：丹药「亮」得不正常，夹着锁魂尾韵（不可明拒，拒=当场翻脸）。
3. 他当众服下半枚，另一半借「伤势过重」拖到私下——实则用异纹强行过滤锁魂，杂质与药力一起变成危险催化剂。
4. 苏晚在殿外以天骄身份「路过」，用契约抽痛掩饰，传音：侧殿地下通祭坛。
5. 夜，陈渊在小院中炼化毒丹；异纹与祭阵同源气味共鸣，记忆碎片闪过：有人把自己的名字写进名单时在笑。

**吞食记录：**
- 半枚筑基丹药力 + 锁魂杂质（强制炼化）
- 异纹：II 级，衣领难遮，需改装高领

**兑现：** 身体被推到筑基临界；同时确认周长老要控他神魂

**章末钩子：** 窗外杀气拢来——不是比武，是灭口。

## 第10章｜筑基

**本章任务：** 第一次大跃迁 + 卷一上半收束；暗杀令落地。

**开场：** 三名黑衣筑基杀手破窗；指令是「留尸，取心头血」。

**过程：**
1. 陈渊不守屋，把战场拖到废弃灵田——那里废料亮点多，可借环境。
2. 苦战：一死一逃一被擒。陈渊对擒者神魂重创，吞其「隐匿呼吸法」前半（为第11章完整化预留）。
3. 生死关头，毒丹催化剂+筑基感悟+异纹共鸣齐爆，强行破境。
4. 筑基成功的气机冲天，外门震感；王墨执事远望失色。
5. 陈渊留下活口传话：告诉周长老，下次祭天换他上来。
6. 远处山门方向，清道者级的「注视感」一闪即逝（异纹 II 级的代价预告）。

**吞食记录：**
- 杀手隐匿呼吸法（半）
- 破境催化完成
- 异纹：II 级稳定；首次明确「被天外注视」

**兑现：** 废脉祭品 → 筑基修士；外门格局改写

**章末钩子：** 周长老密室下令：「缉拿陈渊。若异纹属实，活祭升级——开膛给清道者看。」
