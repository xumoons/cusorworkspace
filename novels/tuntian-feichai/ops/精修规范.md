# 精修规范（POLISH）

## 目标
把「可连载骨架」抬到「愿追更」：压流水句、厚人物、稳节奏。

## 硬禁令
1. **禁止「A则B，B则C」长链**（「则」密度建议 < 8/千字；终局章 < 12/千字）
2. 禁止用概念口号替代场景（少写「可吞可不吞」空转，多写一次具体选择）
3. 禁止同伴工具化：苏晚/阿石/小蔓每出场至少有一句「只有她/他会说」的话
4. 禁止章末用目录式复述剧情

## 精修优先级
1. 卷五终局（最伤）→ 140–150、关键对决章
2. 卷三–四高「则」密度章
3. 卷一人物戏加深（7/12/19/25）作标尺，不大改情节

## 验收
- 字数仍 ≥2500
- `则`/千字下降到规范内
- 读感：有对话、有停顿、有动作，不像细纲朗读
