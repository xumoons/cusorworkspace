# 《吞天从废柴开始》立项总纲

## 执行决策（按优先级）

本项目按以下顺序推进，不再征求方向确认：

1. **锁设定** — 力量体系、吞食规则、代价与禁区（防崩书）
2. **扩细纲** — 第4–10章写到「可直接开写」粒度
3. **固化开篇** — 第1–3章成稿入库，作为文风与节奏标尺
4. **定运营** — 更新节奏、爽点密度、评论话题位
5. **再往下** — 第11–30章按同标准扩写，并开写第4章

## 一句话卖点

被宗门当祭品的废脉少年，觉醒「万法皆可吞」——别人的功法、血脉、秘宝，都能拆了当踏脚石。

## 读者承诺

1. 越战越强，吞一次升一截
2. 身份层层反转：祭品 → 变数 → 执掌者
3. 每个反派都「活该被吞」

## 核心差异

| 常见套路 | 本作 |
|----------|------|
| 系统发奖 | 无系统，吞食有规则与代价 |
| 单纯打脸 | 打脸 = 资源获取 |
| 开局无敌 | 早期弱，靠选对猎物翻盘 |
| 地图换皮 | 每卷换舞台与规则上限 |

## 文风标尺

- 冷静、干脆、少抒情
- 战斗写「选择与代价」，不写无意义炫技
- 每章必须有：目标 / 阻碍 / 兑现或推进 / 钩子
- 禁止注水：无信息增量的日常不超过半章
